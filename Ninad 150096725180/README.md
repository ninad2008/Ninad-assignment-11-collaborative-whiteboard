# Real-Time Collaborative Whiteboard

A collaborative whiteboard application built with Node.js, Express, Socket.io, and HTML5 Canvas.

## Features
- Multi-user whiteboard rooms
- Real-time drawing synchronization
- Live cursor tracking
- In-memory stroke history buffer
- Undo and Clear canvas functionality

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the server:
   ```bash
   npm run dev
   ```
3. Open `http://localhost:5000` in multiple browser windows to collaborate in real-time.
